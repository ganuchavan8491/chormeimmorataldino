# 🦖 Chrome Immortal Dino Game (Modded)

This is a **modded version of the classic Chrome Dino game** where the player becomes *immortal* — no obstacles can stop you! Just run endlessly and enjoy the chaos.

---

## 🎮 What’s Special?

- 🦺 Immortality enabled (you can’t lose)  
- 🔁 Endless running fun  
- ⚡ JavaScript code injected into the real Chrome dino game  
- 🤓 Fun project to explore browser hacks and JS game mods

---

## 🛠️ How to Use

1. Open Google Chrome **offline** or go to:  
   ```
   chrome://dino
   ```

2. Open Developer Tools (Press `F12` or `Ctrl+Shift+I`)  
3. Go to the **Console** tab  
4. Paste the script from `immortal.js` file  
5. Hit Enter and start the game with spacebar

---

## 📁 Files

- `immortal.js` → JavaScript snippet to activate immortality
